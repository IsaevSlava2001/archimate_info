# 🏛️ База знаний ArchiMate

Добро пожаловать в персональную базу знаний по нотации **ArchiMate 3.2**. 
Это хранилище создано для изучения, повторения и практического применения языка архитектуры предприятия.

## 🗺️ С чего начать?
Переходи в главную карту знаний: **[[Главная MOC]]**

## 📂 Структура хранилища (Папки)
- `00_MOC` — Карты контента (Maps of Content). Оглавления и точки входа.
- `01_Core` — Фундаментальные понятия (Ядро, Аспекты, Внутреннее/Внешнее).
- `02_Strategy_Motivation` — Стратегический и Мотивационный слои.
- `03_Business` — Бизнес-слой (Кто, что и как делает).
- `04_Application` — Слой приложений (Чем автоматизирован бизнес).
- `05_Technology_Physical` — Технологический и Физический слои.
- `06_Implementation` — Слой внедрения и миграции (Проекты, Плато, Разрывы).
- `07_Relationships` — Все 11 типов связей и правила их вывода.
- `99_Templates` — Шаблоны для быстрого создания заметок.

## 🏷️ Система тегов (Как я фильтрую информацию)
Каждый элемент (карточка) имеет 4 обязательных тега. Это позволяет мгновенно находить нужные элементы.

1. **Слой (Layer):** `#layer/business`, `#layer/app`, `#layer/tech`, `#layer/motivation`, `#layer/strategy` и т.д.
2. **Аспект (Aspect):** 
   - `#aspect/active` (Активная структура)
   - `#aspect/behavior` (Поведение)
   - `#aspect/passive` (Пассивная структура)
3. **Scope (Внутреннее/Внешнее):** `#scope/internal` (Кухня) или `#scope/external` (Витрина).
4. **Форма (Form):** `#form/rectangle`, `#form/circle`, `#form/hexagon`.

## 🔷 Золотое правило форм (Как читать схемы)
Если на схеме есть элемент без подписи, смотрим на его форму:
* 🟦 **Прямоугольник** = Структура (Кто или что это?)
* ⚪ **Круг / Овал** = Поведение (Что происходит?)
* ⬡ **Шестиугольник** = Мотивация (Почему мы это делаем?)

## 🛠️ Как добавлять новые заметки
1. Создай новую заметку (Ctrl/Cmd + N).
2. Вызови палитру команд (Ctrl/Cmd + P) -> `Insert template` -> Выбери `Шаблон Элемента` или `Шаблон Связи`.
3. Заполни определение своими словами (не копируй из интернета!).
4. Обязательно свяжи элемент с другими через `[[двойные скобки]]`.
5. Не забудь проставить теги в свойствах (вверху файла между `---`).

## 💡 Полезные плагины
- **Templates (Встроенный):** Для быстрого создания карточек.
- **Canvas (Встроенный):** Для рисования схем и метамоделей (папка `00_MOC`).
- **Dataview (Опционально):** Для автоматической сборки таблиц элементов на основе тегов.
