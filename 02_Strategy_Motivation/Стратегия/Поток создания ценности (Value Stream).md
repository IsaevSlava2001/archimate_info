# Поток создания ценности

## 🖼️ Изображение
![[value stream.png]]

## 📖 Определение
Последовательность этапов, которые организация выполняет для создания общего результата (продукта или услуги) для клиента. Поток показывает, как ценность проходит через организацию к потребителю.

## 💡 Ассоциация
«Конвейер для клиента». Путь, который проходит заказ с момента запроса до получения.

## 🌟 Пример
Поток «Покупка билета»: Выбор рейса ➔ Ввод данных пассажира ➔ Оплата ➔ Получение электронного билета.
